# Shared agent handoff

This repository is edited by Codex and Antigravity. At the start of each task, read `.codex/prompt.md` and `.codex/handoff.md` alongside the user's request. Follow the collaboration and handoff procedure in `.codex/prompt.md`.

After each meaningful implementation or documentation iteration, update `.codex/handoff.md` in the same work session. Record what changed, what was verified, what remains, and which agent made the entry. Never place API keys, tokens, customer data, or `.env` contents in these files.
